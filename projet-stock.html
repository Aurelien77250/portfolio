Application de Gestion de Stock

Python SQL · Base de données Tkinter GUI CRUD
Contexte du projet

BTS SIO — Cours de développement — Dans le cadre du BTS SIO, ce projet de développement d'application avait pour objectif de mettre en pratique les compétences techniques acquises : développement Python, gestion de base de données SQL, et conception d'une interface utilisateur. L'application devait être fonctionnelle de bout en bout, de l'authentification à la gestion complète d'un stock de produits.

Objectifs du projet

L'application de gestion de stock devait répondre à plusieurs exigences fonctionnelles et techniques :

  • Authentification sécurisée — système d'inscription et de connexion avec vérification des identifiants stockés en base de données.
  • Gestion des produits (CRUD) — ajouter, modifier, supprimer et lister les articles du stock avec leur nom, quantité et prix.
  • Interface graphique (GUI) — interface claire et accessible via Tkinter pour une utilisation sans ligne de commande.
  • Persistance des données — toutes les données (utilisateurs, stock) stockées de façon permanente en base SQL.
  • Export CSV — possibilité d'exporter le stock au format CSV pour exploitation externe.
Prérequis & Environnement

La mise en place du projet nécessite les outils suivants :

Python 3 Langage principal — interpréteur + bibliothèques standard
VS Code IDE utilisé pour l'écriture et le débogage du code
SQLite / SQL Base de données embarquée pour le stockage persistant
Tkinter Bibliothèque GUI intégrée à Python pour l'interface graphique
Procédure Technique

Le développement de l'application s'est déroulé en 6 étapes progressives, de la mise en place de l'environnement jusqu'aux améliorations finales :

Étape 1
Préparation de l'environnement
Mise en place du poste de travail avant tout développement.
  • Installation de Python 3 et configuration des variables d'environnement.
  • Configuration de VS Code avec les extensions Python (Pylance, debugger).
  • Création de l'arborescence du projet : dossiers src/, db/, export/.
  • Initialisation d'un environnement virtuel Python (venv).
Étape 2
Structure & Base de données
Initialisation des fichiers sources et de la base de données SQL.
  • Création des fichiers principaux : Stock.py, Inscription.py, Connexion.py.
  • Création de la base de données SQLite stock.db via Python.
  • Définition des tables SQL : utilisateurs (id, login, mdp) et produits (id, nom, quantité, prix).
  • Mise en place des fonctions de connexion à la base (sqlite3.connect()).
Étape 3
Module Authentification
Sécurisation de l'accès à l'application par un système login/mdp.
  • Formulaire d'inscription : saisie nom d'utilisateur + mot de passe, enregistrement en base.
  • Module de connexion : vérification des identifiants saisis face aux données SQL.
  • Gestion des erreurs : message d'alerte si identifiants incorrects ou compte inexistant.
  • Redirection conditionnelle vers le menu principal après connexion réussie.
Étape 4
Fonctions Backend — CRUD
Développement du cœur fonctionnel de l'application.
  • Create — ajout d'un produit (nom, quantité, prix unitaire) via formulaire.
  • Read — affichage du stock complet sous forme de liste triable.
  • Update — modification d'un article existant sélectionné dans la liste.
  • Delete — suppression d'un produit avec confirmation avant action.
Étape 5
Logique Utilisateur
Gestion de la navigation et de l'expérience utilisateur dans l'application.
  • Menu principal conditionnel : accessible uniquement après authentification réussie.
  • Gestion des sessions : état de connexion maintenu pendant toute la durée d'utilisation.
  • Actions disponibles filtrées selon le profil utilisateur (admin / standard).
  • Persistance garantie : toute modification est immédiatement sauvegardée en base SQL.
Étape 6
Interface graphique & Export
Finalisation du projet avec l'interface Tkinter et les fonctionnalités avancées.
  • Intégration de l'interface graphique Tkinter : fenêtres, formulaires, tableaux, boutons.
  • Remplacement du menu console par une GUI complète et intuitive.
  • Fonctionnalité d'export CSV : génération d'un fichier exportable depuis le tableau de stock.
  • Tests fonctionnels et corrections de bugs avant validation finale.
