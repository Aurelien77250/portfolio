Partage de fichiers, mapage lecteur réseau et quotas

Windows Server Active Directory GPO SMB Partage réseau
Procédure complète — Partage de fichiers & Mapage lecteur réseau
Documentation technique avec captures d'écran pas à pas
Contexte du projet

Dans le cadre de ma formation BTS SIO SISR, j'ai réalisé un TP complet portant sur la mise en place d'un partage de fichiers sécurisé sur Windows Server. L'objectif était de configurer un dossier partagé en réseau avec une gestion fine des droits par groupes Active Directory, d'automatiser le mapage des lecteurs réseau via une GPO, puis d'appliquer des quotas de stockage pour limiter l'espace disque par utilisateur.

Étapes de réalisation
Étape 1
Création du dossier partagé (Partage1)

Création du dossier partage1 sur le serveur, puis configuration du partage avancé via les propriétés Windows.

  • Clic droit → Propriétés → Partage → Partage avancé
  • Activation de "Partager ce dossier"
  • Ajout du groupe Administrateurs avec Contrôle total
  • Répétition pour chaque groupe avec les droits adaptés
Étape 2
Sécurisation NTFS — Désactivation de l'héritage

Configuration de la deuxième barrière de sécurité via les permissions NTFS, indépendantes des droits de partage.

  • Propriétés → Sécurité → Paramètres avancés
  • Désactivation de l'héritage et suppression de toutes les autorisations héritées
  • Ajout manuel des groupes AD avec les droits appropriés
Étape 3
Vérification du partage réseau

Test de connexion au partage depuis un poste client en saisissant l'IP du serveur dans l'explorateur de fichiers.

\\10.10.10.1

Le dossier partage1 apparaît dans les ressources réseau, confirmant que le partage est fonctionnel.

Étape 4
Mapage manuel du lecteur réseau (net use)

Utilisation de la commande net use pour mapper manuellement le lecteur réseau.

net use L: \\10.10.10.1\Partage1

Le lecteur L: apparaît dans l'explorateur de fichiers sous "Emplacements réseau".

Étape 5
Mapage automatique via GPO

Automatisation du mapage à chaque connexion utilisateur grâce à une Stratégie de Groupe (GPO).

  • Gestionnaire de stratégie de groupe → Créer un objet GPO "Lecteur"
  • Configuration utilisateur → Préférences → Paramètres Windows → Mappages de lecteurs
  • Action : Créer — Emplacement : \\10.10.10.1\Partage1 — Lettre : Y
  • Lier la GPO à l'OU cible dans l'AD
Étape 6
Mise en place des quotas de stockage

Limitation de l'espace disque par utilisateur via un Partage SMB avancé depuis le Gestionnaire de serveur.

  • Gestionnaire de serveur → Fichiers et stockage → Nouveau partage → SMB avancé
  • Création du partage partage2, désactivation de l'héritage, attribution des droits par groupe
  • Application du quota : Limite de 10 Go avec seuils de notification à 85%, 95% et 100%
Compétences acquises
  • Partage Windows Server :  Configuration d'un partage SMB sécurisé avec droits par groupe.
  • Permissions NTFS :  Désactivation de l'héritage et gestion fine des droits de sécurité.
  • Active Directory :  Attribution des droits par groupes de sécurité AD.
  • GPO :  Création et déploiement d'une stratégie de groupe pour le mapage automatique des lecteurs réseau.
  • Quotas de stockage :  Mise en place de limites d'espace disque avec alertes par e-mail.
